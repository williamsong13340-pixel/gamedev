# 风格规范（Art Bible）

> 目的：让几百张 AI 生成的图看起来像同一个美术做的。
> 规则一旦定下就不随意改；要改就改这里和 `prompts/style.json`，然后全量检查。

## 1. 核心原则

1. **列车和世界的运动交给引擎**（视差、颠簸、车轮、粒子、光影）。**人物动作由 AI 直接画成动作帧**（不用骨骼拆件，见第 6 节）。
2. **永远"改模板"，尽量不"从零生成"。** 车厢、车头、房间、人物都基于 `templates/` 里的灰模改画。
3. **每次生成都附上风格锚点图** `art/anchor/style_anchor.png`。
4. **提示词只从 `prompts/style.json` 拼装**，不在批次文件里临时改风格措辞。
5. **新资产必须和已有资产并排对比后才收录。**

## 2. 视角与规格

| 项目 | 规则 |
|---|---|
| 车外视角 | 严格正侧面（orthographic side elevation），无透视、无消失点 |
| 车内视角 | 剖面图：近侧墙被移除，正对后墙，无透视 |
| 行驶方向 | 向右。车头在最右，车厢向左排开 |
| 车厢画布 | 1536×1024，车轮触轨线 y=860，车身 x 140–1396 |
| 车厢连接长度 | 1352 px（挂钩尖到挂钩尖），引擎按此间距排列 |
| 车内地板线 | 人物脚底 y=700，可行走范围 x 190–1346 |
| 人物画布 | 1024×1536，约 4 头身，3/4 侧身朝右（向左走时水平翻转） |
| 人物身高 | 头顶 y≈170 到脚底 y≈1413（入游戏后按车厢比例缩放） |

所有精确坐标（车轮中心、挂钩、窗户、门洞、人物关节点）在 `templates/templates.json`，由 `tools/make_templates.py` 生成，引擎直接读取。

## 3. 色板

| 用途 | 色值 | 说明 |
|---|---|---|
| 最深阴影 / 夜空 | `#1B2433` | 深海军蓝，代替纯黑 |
| 钢铁 / 阴影中间调 | `#3C4A5C` | 石板蓝灰 |
| 冰 / 远景 | `#7FA3B8` | 冰蓝 |
| 雪 / 高光 | `#E8EEF2` | 偏蓝的白，不用纯白 |
| 铁锈 | `#7A4A32` | 补丁、旧金属 |
| 旧木 | `#5C4636` | 木板、家具 |
| 琥珀灯光 | `#F2A65A` | 车窗、油灯 |
| 炉火橙 | `#E8692C` | 火焰、炉膛 |
| 暖光高亮 | `#FFD89A` | 光源中心 |

**铁律：暖色只用于光源**（灯、窗、火）。冷暖对比就是这个游戏的视觉灵魂。

## 4. 光照、线条、质感

- 车外：冷色环境光 + 左上方柔和主光；光源（窗、灯、火）自发光，带辉光
- 车内：以室内暖光为主，窗外透进冷蓝光
- 线条：统一粗细的细深棕色描边（绘本风方案）；纸艺风方案无描边、靠纸层阴影
- 质感：轻微纸张颗粒；最多两级明暗；渐变只用于天空和光晕

## 5. 风格方向（待定）

第一批出图（`prompts/batch-001-style-explore.json`）同时测试三个方向，选定后把对应的 key 写进后续批次的 `defaults.style`：

| key | 方向 | 说明 |
|---|---|---|
| `storybook` | 绘本感半扁平插画 | 形状干净、AI 出得稳、好抠图、动作帧最容易保持一致（推荐） |
| `papercraft` | 剪纸 / 纸艺风 | 手工纸艺质感，统一感强，市面上少见 |
| `silhouette` | 大气剪影层 | 统一感极强，但人物个性表现弱 |

## 6. 人物动画

`templates/character_pose.png` 那个灰色小人**只是给 AI 的站位模特**：统一所有角色的身高、比例和朝向。玩家永远看不到它。

人物动作不用骨骼拆件，而是让 AI 直接画动作帧。两种方法，先做对比测试再定：

| 方法 | 流程 | 特点 |
|---|---|---|
| A. Sunburst 序列图 | 角色立绘 → 一张 4×2 的 8 帧动作图 → `tools/sprites.py sheet` 自动切帧、去背景、对齐 | 便宜、和静态美术同一个模型，风格最统一；帧间一致性需要实测 |
| B. Sora 图生视频 | 角色立绘放到纯绿背景作为第一帧 → 4 秒视频 → `tools/sprites.py video` 自动抽帧、抠绿、找无缝循环 | 动作最自然流畅；按秒计费，比 A 贵 |

对比测试：`prompts/batch-003-anim-test.json`（A）和 `prompts/video-001-anim-test.json`（B）用同一个角色做"走路"和"干活"，结果放进同一个对比页面（`tools/sprites.py preview`）。

量产规则（定方法后执行）：

- 每个角色 × 每个动作都是独立的帧序列，所以**角色数量要克制**：先 8～12 个职业角色，每个 4～6 个动作（待机、走路、干活、坐、睡、吃）
- 每个动作 8～12 帧，10～12 fps；游戏内人物显示高度约 200～400 px，只加载当前车厢里的人物
- 帧必须脚底对齐（工具自动完成），朝右绘制，向左走时水平翻转

## 7. 资产验收清单

- [ ] 轮廓、尺寸、车轮/挂钩/窗户位置与模板一致（叠在模板上检查）
- [ ] 背景真正透明，边缘无残留色边
- [ ] 色板没有跑偏（暖色只出现在光源上）
- [ ] 描边粗细、明暗级数与锚点图一致
- [ ] 与已有资产并排看，比例和细节密度一致
- [ ] 无文字、水印、多余物体

## 8. 出图流程

1. `python3 tools/imagegen.py prompts/batch-001-style-explore.json` → 三个方向共 9 张
2. 选定一张 → 复制为 `art/anchor/style_anchor.png`，把风格 key 写进后续批次
3. 人物动画对比测试（第 6 节）→ 定下人物动画方法
4. `batch-002-rolling-stock.json` → 车头与车厢（外观 + 对应内部）
5. 之后：量产人物与动作；场景物件套件；UI
