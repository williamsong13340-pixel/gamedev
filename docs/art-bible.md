# 风格规范（Art Bible）

> 目的：让几百张 AI 生成的图看起来像同一个美术做的。
> 规则一旦定下就不随意改；要改就改这里和 `prompts/style.json`，然后全量检查。

## 1. 核心原则

1. **AI 只画静态零件，动全部交给引擎。** 不让 AI 画逐帧动画。
2. **永远"改模板"，尽量不"从零生成"。** 车厢、车头、房间、人物都基于 `templates/` 里的灰模改画。
3. **每次生成都附上风格锚点图** `art/anchor/style_anchor.png`。
4. **提示词只从 `prompts/style.json` 拼装**，不在批次文件里临时改风格措辞。
5. **新资产必须和已有资产并排对比后才收录。**

## 2. 视角与规格

| 项目 | 规则 |
|---|---|
| 车外视角 | 严格正侧面（orthographic side elevation），无透视、无消失点 |
| 车内视角 | 剖面图：近侧墙被移除，正对后墙，无透视 |
| 行驶方向 | 向右。车头在最右，车厢向左排开 |
| 车厢画布 | 1536×1024，车轮触轨线 y=860，车身 x 140–1396 |
| 车厢连接长度 | 1352 px（挂钩尖到挂钩尖），引擎按此间距排列 |
| 车内地板线 | 人物脚底 y=700，可行走范围 x 190–1346 |
| 人物画布 | 1024×1536，约 4 头身，3/4 侧身朝右（向左走时水平翻转） |
| 人物身高 | 头顶 y≈170 到脚底 y≈1413（入游戏后按车厢比例缩放） |

所有精确坐标（车轮中心、挂钩、窗户、门洞、人物关节点）在 `templates/templates.json`，由 `tools/make_templates.py` 生成，引擎直接读取。

## 3. 色板

| 用途 | 色值 | 说明 |
|---|---|---|
| 最深阴影 / 夜空 | `#1B2433` | 深海军蓝，代替纯黑 |
| 钢铁 / 阴影中间调 | `#3C4A5C` | 石板蓝灰 |
| 冰 / 远景 | `#7FA3B8` | 冰蓝 |
| 雪 / 高光 | `#E8EEF2` | 偏蓝的白，不用纯白 |
| 铁锈 | `#7A4A32` | 补丁、旧金属 |
| 旧木 | `#5C4636` | 木板、家具 |
| 琥珀灯光 | `#F2A65A` | 车窗、油灯 |
| 炉火橙 | `#E8692C` | 火焰、炉膛 |
| 暖光高亮 | `#FFD89A` | 光源中心 |

**铁律：暖色只用于光源**（灯、窗、火）。冷暖对比就是这个游戏的视觉灵魂。

## 4. 光照、线条、质感

- 车外：冷色环境光 + 左上方柔和主光；光源（窗、灯、火）自发光，带辉光
- 车内：以室内暖光为主，窗外透进冷蓝光
- 线条：统一粗细的细深棕色描边（绘本风方案）；纸艺风方案无描边、靠纸层阴影
- 质感：轻微纸张颗粒；最多两级明暗；渐变只用于天空和光晕

## 5. 风格方向（待定）

第一批出图（`prompts/batch-001-style-explore.json`）同时测试三个方向，选定后把对应的 key 写进后续批次的 `defaults.style`：

| key | 方向 | 说明 |
|---|---|---|
| `storybook` | 绘本感半扁平插画 | 形状干净、AI 出得稳、好拆件（推荐） |
| `papercraft` | 剪纸 / 纸偶风 | 关节动画的"纸片感"直接成为美术特色 |
| `silhouette` | 大气剪影层 | 统一感极强，但人物个性表现弱 |

## 6. 资产验收清单

- [ ] 轮廓、尺寸、车轮/挂钩/窗户位置与模板一致（叠在模板上检查）
- [ ] 背景真正透明，边缘无残留色边
- [ ] 色板没有跑偏（暖色只出现在光源上）
- [ ] 描边粗细、明暗级数与锚点图一致
- [ ] 与已有资产并排看，比例和细节密度一致
- [ ] 无文字、水印、多余物体

## 7. 出图流程

1. `python3 tools/imagegen.py prompts/batch-001-style-explore.json` → 三个方向共 9 张
2. 选定一张 → 复制为 `art/anchor/style_anchor.png`，把风格 key 写进后续批次
3. `batch-002-rolling-stock.json` → 车头与车厢（外观 + 对应内部）
4. 之后：人物模板换装 → 拆件 → 骨骼动画；场景物件套件；UI
