# 情侣小游戏（重做版）

用户买的原网站（版权已买断，但商家没给源码就跑路了，只剩网址）bug 多、界面乱、玩法说不清，所以这里重新做一个干净的手机版。

## 现在有什么

三个游戏都可以完整玩，共用一套界面和题库：

- **心动卡牌**：轮流从三张盖着的牌里翻一张，照做得一颗心；先集满的人向对方许一个愿望。
- **真心话大冒险**：转盘选人（同一人最多连着两次），被选中的人自己挑真心话或大冒险；每轮可换一题；连选两次真心话后只能选大冒险。
- **双人飞行棋**：30 格棋盘，掷骰子前进，停在哪格做哪类事；不做就后退 2 格；惊喜格有前进、后退、再掷、换位。

共同点：

- 轮到谁，整个屏幕就是谁的颜色（玫红 / 紫）；橙=行动，青=真心话，金=惊喜。
- 真洗牌、一轮内不重复、连点不会出错、刷新后可以继续上一局。
- 不联网，所有内容只存在手机本地。

## 内容从哪来

1. **自带题库**：初见 / 热恋 / 深夜，偏温和，写在 `src.html` 的 `const DECKS` 里。
2. **专属内容**：用户在游戏里自己写，一行一条，问号结尾算真心话。
3. **导入题库**：开局设置页点"导入题库"，选一个 `.json` 文件。原网站的内容就是这样进来的——导出文件直接交给用户本人，**不放进仓库，也不写进代码**。

导入文件格式：

```json
{"format": "couple-games-import-v1",
 "decks": [{"name": "恋爱版", "game": "cards", "d": ["行动…"], "s": ["真心话…"]}]}
```

`game` 是 `cards`、`tod`（真心话大冒险）或 `chess`（飞行棋）。

## 文件

| 文件 | 说明 |
|---|---|
| `src.html` | 全部代码和自带题库都在这一个文件里 |
| `build.py` | `python3 build.py` 把 `src.html` 包成 `index.html` |
| `index.html` | 生成的完整页面，手机浏览器可直接打开 |
| `preview/` | 界面总览图 |

改了 `src.html` 之后记得重新运行 `python3 build.py`。
