# 情侣小游戏（重做版）

原来买的那个网站（只有网址和账号，改不了）bug 多、界面乱、玩法说不清，所以这里重新做一个干净的手机版。

## 现在有什么

- **首页**
- **心动卡牌**（可以完整玩）：轮流从三张盖着的牌里翻一张，照牌上写的做，做完得一颗心；先集满的人向对方许一个愿望。
  - 三副牌：初见 / 热恋 / 深夜，另外可以自己写"专属"卡牌
  - 牌背颜色区分三类：行动（橙）、真心话（青）、惊喜（金）
  - 轮到谁，整个屏幕就是谁的颜色（玫红 / 紫）
  - 真洗牌、整副牌翻完之前不重复、连点不会出错、刷新后可以继续上一局
  - 不联网，所有内容只存在手机本地
- 真心话大冒险、双人飞行棋：还没做

## 文件

| 文件 | 说明 |
|---|---|
| `src.html` | 全部代码和题库都在这一个文件里。改题库：找 `const DECKS`。 |
| `build.py` | `python3 build.py` 把 `src.html` 包成 `index.html` |
| `index.html` | 生成的完整页面，手机浏览器可直接打开，也可以放到任何静态网站空间 |
| `preview/` | 界面总览图 |

改了 `src.html` 之后记得重新运行 `python3 build.py`。
